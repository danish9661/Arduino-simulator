SPI Radio (CSN/GDO)

Sensors

Reference SPI radio component template for driver bring-up. CSN controls transaction selection while GDO0/GDO2 provide GPIO-style interrupt/status outputs.

Pins

PinTypeDescription
MOSI/MISO/SCK/CSNDigitalSPI interface. CSN is active-low.
GDO0/GDO2DigitalIRQ/status outputs. Model as GPIO interrupts.
VCC/GNDPowerSupply rails (prefer 3.3V logic).

Attributes

AttributeDefaultDescription
irqOnWritetrueRaise GDO outputs after FIFO writes.
whoAmI0x42Value returned by identity register.

Wiring

MCU MOSI  -> MOSI
MCU MISO  -> MISO
MCU SCK   -> SCK
MCU GPIO  -> CSN (drive LOW during transfer)
MCU GPIO  <- GDO0 / GDO2 (interrupt inputs)

Example Code

// Pseudocode
csnLow();
spiTransfer(0x80 | 0x00); // read WHO_AM_I register
byte id = spiTransfer(0x00);
csnHigh();
Tip: Keep CSN wiring explicit. Even though the simulator supports no-CS SPI components, radios should always have CSN for deterministic multi-slave behavior.
